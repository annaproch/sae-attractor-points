# WikiText paragraph sample

This directory contains 100 Wikipedia-derived paragraphs from
[Salesforce/wikitext](https://huggingface.co/datasets/Salesforce/wikitext),
configuration `wikitext-2-raw-v1`, `test` split. Credit goes to Wikipedia
contributors and the WikiText dataset authors Stephen Merity, Caiming Xiong,
James Bradbury, and Richard Socher.

See [the WikiText third-party notice](../../THIRD_PARTY_NOTICES.md#wikipedia-text-distributed-through-wikitext)
for license links, the upstream license-version discrepancy, and a description
of local processing. Preserve that notice with copies of the text, including
text embedded in experiment outputs. The manifest and each record's
`source_row` provide dataset-level provenance.
